# 日本語・英語UI

英語UIは日本語の表示内容を基準に実装します。通常画面では短い表示名を使用し、仮定や取得範囲はツールチップと詳細画面で説明します。研究画面の情報量は維持します。

| 日本語 | 英語 | 意味 |
| --- | --- | --- |
| 実使用 | Actual use | 観測した損耗と予測WAFに基づく計算 |
| 保持考慮 | With retention | 電源OFFで指定温度・期間に保管する仮定 |
| クライアント負荷 | Client workload | 将来WAFを設定した負荷比較 |
| 参考基準 | Reference | NANDの情報と論理容量から選択する比較値 |
| 損耗 | Wear | 上部とメニューバーはHost基準。取得できない場合はNAND損耗、次にPercentage Used。TLC／pSLCはP/E基準 |
| 未取得 | Not available | 値を取得できていない状態 |
| 比較待ち | Awaiting comparison | 比較に必要な観測が未充足 |
| 暫定 | Provisional | 代用値・仮定・短期観測を含む推計 |

## 実装方針

SwiftPMのリソースとして日本語・英語の文字列をまとめ、AppKitとSwiftUIで共通の参照方法を使用します。画面に表示する文章を翻訳対象にし、SMARTのフィールド名、FTL key名、単位記号、モデル識別子は原表記を維持します。

保存するdevice ID、系列識別、JSONのkey、enumのrawValueは表示言語から独立させます。エラーの判定に翻訳済みの文字列を使用しません。動的な値はプレースホルダーへ渡し、語順を翻訳側で指定できるようにします。

日時はロケールに合わせて表示し、履歴の保存形式は維持します。グラフの範囲ボタンは日本語・英語それぞれの短い表記に統一し、年を跨ぐ日付と日を跨ぐ時間の追加情報を両言語で維持します。bytesとGB/TB、P/E、％の意味は翻訳で変更しません。

## 確認範囲

ダッシュボード、メニューバー、設定、Researchの順に接続します。空の履歴、取得失敗、暫定、通常データを確認し、英語の長い文言による切れや重なりを実画面で確認します。TLC／pSLCの色と既存のカード配置は維持します。

## 現在の接続範囲

設定の取得間隔、ディスク情報の項目・空状態・識別情報の注意、NAND詳細のdomain／残差／bottleneck項目を英語リソースへ接続しました。ディスクのモデル・シリアル番号・パスと取得JSONは翻訳せず、原文をそのまま表示します。取得間隔の保存値は変更していません。

2026-10-08、SwiftPMの翻訳リソースと共通の参照処理を接続しました。設定の外観に言語選択を追加しています。既定はシステム言語で、日本語以外は英語を使用します。言語変更は再起動せず画面全体へ反映します。表示名、状態、操作ボタンを中心に英語を登録し、未登録の項目は日本語を表示します。

数値入りの登録済み診断書式、Researchの説明、AppKitファイル選択画面のアプリ指定文言、日時・単位書式を接続しました。未知の旧診断書式と外部ツールの原文は翻訳せず保持します。アドホック署名の配布版は別工程で作成します。

Researchの見出し、空の取得状態、topologyと保持条件の項目名、WAF・ペース・観測点数の書式も翻訳へ接続しました。ダッシュボードの期間・集計単位・TLC/pSLC切り替えはアプリの言語設定に従います。raw構造の表示は翻訳せず維持します。

対応状況の理由文は表示用の型別処理で英語へ組み立てる方式を追加しました。日本語の原診断と履歴は変更しません。長基線の基線種別・残差判定・観測見込み・固定注意文、NAND詳細の主要項目名も翻訳対象です。主要な取得／保存エラーは登録済みの説明部分のみを翻訳し、パス・stderrなどの詳細と未知のメッセージは原文を保持します。すべての動的な解析注記、独自日時書式、OSのエラー原文が英語になるわけではありません。

S.M.A.R.T.／FTL照合のHost比・POH差・損耗率差・符号付き残差・量子化範囲・内部活動と、長基線のΔTLC未到達注記は、既知の文章書式に完全一致する場合のみ表示時に英語へ置換します。元の値や判定は再計算しません。未登録の書式は原文のまま残すため、取得ツールの文章変更を誤って意味付けしません。この互換表示処理は保存済み日本語の診断に対するものです。新しい診断を増やす際は、型付きの表示処理を優先します。

画面の取得日時は`yyyy/MM/dd HH:mm`、到達年月は日本語の`yyyy年M月`／英語の`MMM yyyy`で表示します。グラフの`HH:mm`・`MM/dd`・年跨ぎの`yyyy/MM/dd`は両言語で共通です。保存日時、device ID、系列、対応表の名前は表示ロケールに依存しません。

## 未知の診断とrawデータ

言語変更は再起動不要です。Appが言語設定を監視し、メイン画面・メニューバー・Aboutの表示を更新します。監視モデルは維持します。設定画面は自身の言語設定監視で再描画し、選択中のカテゴリを維持します。初期実装での再起動要件は廃止しました。

UIString.messageは未知の診断原文を保持します。UIString.readoutはUIの構造化された区切り欄のみに使用し、raw JSONや書出しデータには使用しません。Researchの旧診断に未登録の文章が残る場合は、英語表示で「Original diagnostic (unregistered format)」と明示して原文を残します。これは操作項目の未翻訳とは分けて扱います。モデル名・シリアル・パス・外部ツールのstderr・OSエラーも原文です。

## 検証と保守

LocalizationTestsは固定コピーの登録、日英表示、取得間隔、未知診断・raw JSONの原文保持、数値入り書式、日付、符号付き残差を確認します。固定コピーを追加するときは英語リソースも同時に更新します。翻訳リソースの構文チェックと重複key検査は別に実施します。

任意プレビューでは明示的に指定した保存データのみを読み込み、設定全カテゴリ、About、ディスク情報、Research全カテゴリ、NAND詳細、寿命予測のライト／ダークを描画します。実収集・負荷試験・利用者設定の変更は行いません。出力はignoredのbuild/english-ui-previewへ保存し、識別情報が含まれ得るため公開・Git登録しません。

ソース・テスト・内部Releaseビルド・署名検証と、インストール・利用者の実画面確認・配布・公開は別工程です。OS管理のダイアログ内文字列はOSの言語設定に従います。

## 言語の切り替えと、確認できている範囲

設定の言語を「システムに合わせる」から英語へ切り替えると、再起動しなくても設定・メイン画面・操作メニューが更新されます。「システムに合わせる」へ戻すと、日本語の画面に戻ります。これらは実機で確認しています。

直近WAFの期間、最小空き容量、境界の凡例、ログイン項目の状態も、表示用の翻訳を通します。英語の温度カードでは、見出しが省略されないようミニグラフを狭くしています。いずれも表示のみの変更で、計算・カウンタ・損耗の色は変更されません。

メニューバーのポップアップ全体と、VoiceOverの読み上げのすべての経路は、まだ実機で確認していません。診断の原文がすべて翻訳されることは、目標にしていません。

### 読み上げ経路の追加整備

ダッシュボード上部のHost読込・Host書込・履歴期間・稼働時間・電源投入・最終取得を、値を保持した翻訳書式へ接続しました。メニューバー項目の状態と、ポップアップのモデル名からメイン画面を開く操作の読み上げもアプリ言語に従います。保持予測とNAND残量のツールチップも表示用翻訳を通します。未知の診断原文と保存データは変更しません。

書式の回帰テストは、モデル名と各計測値が英語ラベルと正しい順序で組み立てられることを確認します。これはソースの読み上げラベル検証であり、VoiceOverによる全操作経路の実機受入確認とは区別します。

### 未取得・失敗状態の判定確認

SMART未導入時はsmartmontools導入コマンド、初回タイムアウト時は再試行案内、既存値があるタイムアウト時は前回値の表示を案内します。履歴なしではFTL区間も予測も補完せず、SMART未取得を正常扱いしません。FTLがない場合のSMART暫定推計は、FTL推計と区別する既存の表示を維持します。

Critical Warningが非ゼロの場合、SMARTの総合判定がtrueまたは欠測であっても状態カードを「要確認」にします。上部見出しと同じ警告条件です。DashboardGuidanceTestsでこれらの判定を検証します。通常監視からsmartctlを除外したり履歴を削除したりはせず、実データと設定を維持したままテストしています。別ハードウェア・未知FTL形式の全画面確認を完了したという意味ではありません。

### 空状態の描画検証

`TemperatureUpdateTests/testOptInEmptyStatePreview`は、`NENRING_EMPTY_PREVIEW_ROOT`を指定した場合のみ、空のDashboard・メニューバー・ディスク情報を描画します。`NENRING_UI_LANGUAGE`で日英を指定できます。メニューバーは`startsMonitoring: false`で描画し、収集を開始しません。通常アプリの既定値はtrueのままです。設定は一時suiteを使用し、テスト後に当該suiteのみを除去します。

2026-10-08、日英・ライト／ダークの空Dashboardとメニューバー、および空のディスク情報を描画しました。英語の容量・取得時刻・残量の欠測表示に日本語が混ざる経路を補完しました。出力はignoredの`build/empty-state-preview`内にのみ配置し、Gitへ登録しません。これは空状態の描画確認であり、メニューバーの実クリックやVoiceOver操作の確認とは異なります。

### 説明ポップアップ

寿命予測の各行にクリックで開く説明ボタンを追加し、動的な保持日数・温度も翻訳書式で表示します。説明本文は親行の1行制限を解除して折り返します。日英の長文を親の1行制限下で描画する回帰テストを追加しました。2026-10-09、インストール後の日本語画面で保持考慮の説明が末尾まで表示され、閉じられることを確認しています。
