# 配布版の作成

当面のNenRingはアドホック署名で配布します。Developer IDによる開発元の確認とAppleの公証は付いていません。配布物はGitHub Releasesに掲載します。

## 作成

リポジトリのルートで次を実行します。

```sh
./scripts/ci-local.sh
zsh scripts/package-release.sh
```

DMGとSHA-256は固定の`build/releases/`へ保存します。DMGにはアプリと`/Applications`へのリンクのみが含まれ、監視履歴・診断レポート・ローカル設定は含みません。スクリプトは作成したDMGを読み取り専用でマウントし、同梱アプリがビルドしたアプリと一致することと、アプリと2本のprobeの署名を確認します。版とソースrevisionは同梱アプリの情報から取得します。未コミットの変更があるビルドには`dirty`が付くため、公開前に対象変更をコミットし、同じ手順で再作成します。

タグは`v<版>`（例：`v0.2.0`）とし、ソースrevisionのコミットに付けます。リリースページには、アドホック署名のみのため初回起動時に許可が必要であること、READMEの導入手順へのリンク、SHA-256を記載します。ビルドと署名検証の後、実際にダウンロードしたDMGから初回起動を確認します。ローカルのアプリが起動したのみでは、この確認を完了扱いにしません。

## 初回起動で確認した内容

macOS 27.2の管理者のアカウントで確認した内容と、まだ確認していない内容です。

- 2026-11-25：GitHub Releasesからブラウザでダウンロードした0.2.0のDMGで、次を確認しました。
  - 起動時の警告のボタンは「閉じる」と「ゴミ箱に入れる」のみで、起動を続ける選択肢はありません。
  - 「システム設定」→「プライバシーとセキュリティ」で「このまま開く」を選択すると管理者の認証が求められ、認証後に起動します。
  - 既存のアプリを置き換えても履歴と設定が引き継がれます。置き換え前のバックアップと照合し、欠けた記録がないことを確認しました。
- 2026-11-07：ダウンロード済みを示す拡張属性（`com.apple.quarantine`）を付けたDMGで、DMGが警告なしで開けることを確認しました。管理者でないアカウントでは「このまま開く」が表示されませんでした（1回のみの確認であり、原因は特定していません）。
- 未確認：新しいバージョンへ置き換えた後に、再度許可が必要かどうか。
