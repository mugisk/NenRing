# アドホック署名の実験版

当面のNenRingはアドホック署名で配布します。Developer IDによる開発元の確認とAppleの公証は付いていません。配布物はGitHub Releasesへ掲載する予定ですが、公開操作は別途行います。

リリース作成は日本語UI・英語UI・公開文書の整備とリポジトリ公開の後に行う最終工程です。この文書は作成手順を説明するもので、配布版の公開を示すものではありません。

## 作成

リポジトリのルートで次を実行します。

```sh
./scripts/ci-local.sh
zsh scripts/package-experimental.sh
```

DMGとSHA-256は固定の`build/releases/`へ保存します。DMGにはアプリと`/Applications`へのリンクのみが含まれ、監視履歴・診断レポート・ローカル設定は含みません。スクリプトは作成したDMGを読み取り専用でマウントし、同梱アプリがビルドしたアプリと一致することと、アプリと2本のprobeの署名を確認します。版とソースrevisionは同梱アプリの情報から取得します。未コミットの変更があるビルドには`dirty`が付くため、公開前に対象変更をコミットし、同じ手順で再作成します。

リリースページには版、ソースrevision、必要環境、smartmontoolsの導入方法、未公証であること、SHA-256を記載します。ビルドと署名検証の後、実際にダウンロードしたDMGから初回起動を確認します。ローカルのアプリが起動したのみでは、この確認を完了扱いにしません。

## 利用者向けの導入手順（README掲載用の下書き）

次の節は配布版の公開時にREADMEの「インストール」へ掲載する文面の下書きです。公開前のため、READMEにはまだ掲載しません。

### インストール（配布版）

NenRingの配布版はGitHub ReleasesからDMG形式で提供します。配布版はアドホック署名のみで、Appleによる公証を受けていません。そのため、初回起動時にmacOSでの許可の操作が必要です。

1. **ダウンロード**：Releasesのページから、`NenRing-<バージョン>-<revision>-experimental.dmg` と、同名の `.sha256` ファイルをダウンロードします。
2. **チェックサムの確認**：ターミナルで次のコマンドを実行します。ファイル名はダウンロードしたものに置き換えてください。

   ```sh
   cd ~/Downloads
   shasum -a 256 -c NenRing-<バージョン>-<revision>-experimental.dmg.sha256
   ```

   「OK」と表示されれば、ダウンロードしたファイルは配布したものと一致しています。「FAILED」と表示された場合は使用せず、ファイルを削除してください。
3. **アプリのコピー**：DMGを開き、NenRing.appを同じウインドウ内の「Applications」へドラッグします。DMG内のアプリは直接起動せず、コピーしたアプリを起動してください。
4. **初回起動の許可**：コピーしたNenRing.appを開くと、Appleが検証できないアプリとして起動が停止されます。この警告には起動を続ける選択肢がありません。警告を閉じた後、「システム設定」→「プライバシーとセキュリティ」を開き、NenRingの「このまま開く」を選択すると起動します。詳細はAppleのサポート記事「[Macでアプリを安全に開く](https://support.apple.com/ja-jp/102445)」を参照してください。
5. **smartmontoolsの導入**：未導入の場合は、[smartmontoolsの導入](#smartmontoolsの導入)の手順に従ってください。

以前のバージョンから更新する場合は、NenRingを完全に終了（⌥⌘Q）してから、手順3で既存のアプリを置き換えます。記録済みの履歴と設定はアプリとは別の場所に保存されているため、そのまま引き継がれます。

破損やマルウェアの検出を示す警告が表示された場合は、起動を中止し、ダウンロード元とチェックサムを確認してください。Gatekeeper全体を無効にする操作は不要であり、推奨しません。組織が管理するMacや、管理者でないユーザーアカウントでは、許可できない場合があります。

アプリの起動の許可と、SSDの詳細統計を取得する権限は別のものです。管理者権限でのprobeの実行条件は[署名検証](PROBE_SIGNATURE.md)を参照してください。

### リリース時に確認する事項

2026-11-07にmacOS 27.2で、ダウンロード済みを示す拡張属性（`com.apple.quarantine`）を付けたDMGを用いて確認した内容と、まだ確認していない内容です。

- 確認済み：DMGは警告なしで開けること。管理者のアカウントで、起動時の警告に「このまま開く」が表示されず、「システム設定」→「プライバシーとセキュリティ」から許可して起動できること。既存のアプリを置き換えても履歴と設定が引き継がれること。
- 確認済み：管理者でないアカウントでは、「このまま開く」が表示されなかったこと（1回のみの確認であり、原因は特定していません）。
- 未確認：GitHub Releasesからブラウザで実際にダウンロードしたDMGでの動作。警告の正確な文面と、許可の際に管理者の認証が求められるかどうか。新しいバージョンへ置き換えた後に、再度許可が必要かどうか。
