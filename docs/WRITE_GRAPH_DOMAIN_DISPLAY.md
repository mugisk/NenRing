# 書込量グラフの読み方

「全体」「内訳」「WAF」を切り替えて表示できます。

「全体」の差分表示ではHost（SMART）とNAND（Direct FTL）の書込量を2本の棒で示します。棒は一部重なりますが、どちらも0から始まり、それぞれの高さが書込量を表します。累計表示ではSSDの累積カウンタの推移を表示します。「内訳」の累計は表示期間の開始から推定書込量を積算した値です。

上段のWAFは同じFTL取得区間で集計したNAND書込量の合計をHost書込量の合計で割った値です。下段にはHost書込量のうちTLCへ直接書き込んだ割合の推定値を表示します。

どちらの計算にもそれぞれに必要なカウンタが揃った取得区間を使います。時間・日・週の集計単位ごとに、対象のHost書込量が1 GB未満なら、その系列の値は表示しません。WAFの折れ線は値のない区間で途切れます。

「内訳」では同じ系列内でNAND構成を比較できる区間を対象に、TLCとpSLCの書込量を推定します。領域ごとに、区間開始時の容量に、その区間の平均P/Eの増分を掛けて求めます。差分表示ではTLCとpSLCの推定書込量を積み上げた棒で示します。実測NANDとの差は各領域に配分せず、容量が不明な区間や比較できない区間は欠測として扱います。予測の学習対象から除外した区間でも、比較可能な推定値があればグラフに表示します。

日単位のグラフでは、2回の測定が日付をまたぐ場合、その間の書込量を午前0時の前後の経過時間に応じて按分します。たとえば、23時50分から翌日0時20分までに30 GBの書込があれば、前日に10 GB、翌日に20 GBを計上します。時間単位・週単位のグラフでも、集計区間をまたぐ場合は同じ方法で按分します。実際に各区間でどれだけ書き込んだかは、この2回の測定からは特定できません。

また、平均P/Eは整数で記録されるため、差分が0でも内部で書込が発生した可能性があります。

グラフ下部のTLC／pSLCの数値は各領域の容量と現在の平均P/Eから求めた累積推定量です。「内訳」の累計グラフとは集計の起点が異なります。
